# Open Tess AI

Простой чат-бот на PyTorch с плагинами, его зовут otai и он улучшенная версия TAIB. Умеет учиться на диалогах и отвечать из словаря.

## Что умеет

- Отвечать на приветствия и простые вопросы
- Генерировать случайные фразы из словаря и шаблонов
- Запоминать диалоги в SQLite
- Дообучаться на новых диалогах (команда `train`)
- Расширяться через плагины

## Как запустить

```bash
pip install torch
python core.py
```

Всё. Бот запустится в консоли.

## Команды

| Команда | Что делает |
|---------|-----------|
| `exit` | Выйти |
| `train` | Дообучить модель на диалогах из БД |

## Плагины

Плагины лежат в папке `plugins/`. Они могут:
- менять сообщения пользователя (`preprocess`)
- генерировать ответ (`generate`) — заменяет ядро
- менять ответ бота (`postprocess`)

## Плагины сообщества

| Плагин | Описание | Автор |
|--------|----------|-------|
| [dictionary_and_templates](в папке plugins) | Генерация ответов из словаря | от меня |


### Готовый плагин: `dictionary_and_templates`

Генерирует ответы из словаря и шаблонов.

Структура:
```
plugins/dictionary_and_templates/
├── plugin.py
├── dictionary.json    # слова по частям речи
└── templates.json     # шаблоны с плейсхолдерами
```

### Шаблоны

```json
{ "id": 1, "group": "base", "template": "Я {verb} {noun}." }
```

Группы: `base`, `question`, `time`, `negative`, `conditional`, `comparison`, `imperative`, `abstract`

## Конфиг

Все настройки в `config.py`. Можно поменять:
- имя бота
- язык
- размер модели
- количество эпох обучения

## Структура проекта

```
├── core.py              # главный файл
├── config.py            # настройки
├── model.py             # нейросеть (Seq2Seq LSTM)
├── trainer.py           # обучение
├── utils.py             # словарь и токенизация
├── db_manager.py        # SQLite
├── plugin_loader.py     # загрузка плагинов
├── models/              # сохранённые модели
└── plugins/             # плагины
```

## Зачем всё это

Проект делался как игрушка / учебный эксперимент. Можно ковырять, добавлять свои плагины и словари, смотреть, как работает простая нейросеть.
